# AP 통계학 I · 시험 직전 정리

AP Statistics I(2026-2학기) 중간고사 직전 정리 사이트입니다. 수업 프린트(Chap 1~3)와 수업 설명을 바탕으로 만들었습니다.

- **1장 일변량 자료**: 용어, 범주형·수치형 표현, SOCS, 중심·위치·퍼짐, 상자그림, 정규분포·경험적 규칙
- **2장 이변량 자료**: 이원표(조건부 분포), 심프슨의 역설, 산점도(FODUS), 상관계수 r, 최소제곱회귀선, 잔차도, r², 이상치·레버리지·영향점, 컴퓨터 출력
- **3장 자료 수집**: 관찰연구·실험, 편향의 종류, 무작위 추출, SRS·층화·군집·계통추출
- 인라인 SVG 그림, 풀이 예제, 연습문제 45개(자가 채점), 플래시카드 99장, 검산 도구(사분위수·상자그림·상관·회귀), 다크 모드

단일 `index.html`(외부 라이브러리 없음, 폰트만 Google Fonts)이며 GitHub Pages로 배포됩니다.
